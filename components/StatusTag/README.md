# StatusTag

A pill of one to three words that states a status; it always carries a word, and an icon where the status is safety-related.

- `go` (green tint): “No lightning nearby”, “Paired”. `confirmed` (solid green): “Booking confirmed”.
- `warning` (amber): “Battery 18%”. `brand` (purple tint): “Walking”, “Riding”.
- `lightning` and `zone` are the fixed safety colours: “Lightning nearby”, “Restricted”.
- Never use a tag as a button.
