# QRPanel

The pairing code on the welcome screen, the primary way to pair: any phone camera opens Teemeup and links the device to the golfer's tee time.

- QR comes first because phone-to-phone NFC with iPhone is unreliable; NFC is a secondary row under it.
- The code sits on white in both themes, with a quiet zone, at least 140px.
- The end-of-round screen reuses it with “Download Teemeup and book your next round.”
- The code in mock-ups is a stand-in pattern; the app renders the real pairing URL.
