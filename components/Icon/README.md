# Icon

The Lucide line icons the cart uses, on a 24px grid with a 2px round stroke in `currentColor`; `TeemeupCart.iconNames` lists them.

- Sizes: 14px in tags, 18px in header status, 20px in buttons, 24–28px in tiles, 48–52px on the mic and takeovers.
- Pass `label` when the icon is the only carrier of meaning; otherwise it is hidden from screen readers.
- Every safety icon appears with its word. Need another Lucide icon? Use `lucide-react` by the same name.
