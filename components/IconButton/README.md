# IconButton

A round icon-only button: 56px by default (the outdoor minimum), 44px in the header.

- `variant="map"` floats over the hole map with `shadow-float`: previous and next hole.
- Always pass `label`; it is the button's only name for screen readers and voice control.
- Back is the only 44px use, inside the 60px header where the whole bar is the target.
