# QuantityStepper

− count + for one line of an order, on the review step. Both buttons are 56px.

- At 1 the minus becomes an ✕ (“Remove Hot dog”), so removing is explicit.
- The count is announced politely to screen readers as it changes.
- `min` keeps the minus sign at the lowest value instead of turning it into ✕ (scores: a 1 is an ace, not a removal).
