# BobAvatar

Bob is always the sparkles icon in a purple circle, never a face, a robot or the Teemeup logo.

- 40px beside chat bubbles, 32px inside the Talk to Bob pill (`onAccent` turns the circle into a white wash on purple), 76–104px on the pairing and splash screens.
- He is named in text wherever he appears: “Bob” above his bubbles, “Talk to Bob” on the bar.
