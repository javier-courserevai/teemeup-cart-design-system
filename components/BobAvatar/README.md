# BobAvatar

Bob is always the sparkles icon in a purple circle, never a face, a robot or the Teemeup logo.

- 40px beside chat bubbles and on his answers, 76–104px on the pairing and splash screens. `onAccent` turns the circle into a white wash for use on purple.
- He is named in text wherever he appears: “Bob” above his bubbles and answers, “Ask Bob” in the Menu · Ask Bob control.
